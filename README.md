# softclaw.ai — Landing Page

Static landing page for softclaw.ai. Single self-contained `index.html` — fonts and images baked in, no build step.

## Deploy to Vercel

1. Push this folder to a GitHub repo (all files at the repo root).
2. Go to [vercel.com/new](https://vercel.com/new) → Import the repo.
3. Framework preset: **Other**. Leave build command and output directory empty.
4. Click **Deploy**.

To use your domain: Vercel → Project → Settings → Domains → add `softclaw.ai`.

## Editing

- Log In / Begin Now buttons open an email to `vidya@softclaw.ai` — search for `mailto:` in `index.html` to change.
